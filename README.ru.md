# opencode-todo

[Português](README.md) · [English](README.en.md) · [Español](README.es.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Русский](README.ru.md) · [हिन्दी](README.hi.md) · [中文](README.zh.md) · [日本語](README.ja.md)

Плагин для [OpenCode](https://opencode.ai) со списком задач для каждой сессии. Агент создаёт и обновляет пункты с помощью инструментов `todo_write` и `todo_list`; TUI показывает прогресс в боковой панели и в отдельной панели, открываемой командой `/todos`.

![Предпросмотр списка задач в боковой панели](docs/todo-preview.svg)

## Возможности

- Отдельный список для каждой сессии, сохраняемый в хранилище OpenCode.
- Субагенты обновляют список корневой сессии.
- Обновление в реальном времени через RPC.
- Значки и цвета в зависимости от статуса, с выравниванием при переносе строк.
- Панель `/todos` для просмотра и очистки списка.

## Установка

Клонируйте репозиторий в папку плагинов OpenCode и установите зависимости:

```bash
git clone https://github.com/juliano340/opencode-todo.git ~/.config/opencode/plugins/opencode-todo
cd ~/.config/opencode/plugins/opencode-todo
npm install
```

В Windows используйте аналогичную папку, например:

```powershell
git clone https://github.com/juliano340/opencode-todo.git "$env:USERPROFILE\.config\opencode\plugins\opencode-todo"
cd "$env:USERPROFILE\.config\opencode\plugins\opencode-todo"
npm install
```

Добавьте абсолютный путь к папке в поле `plugins` глобального файла `opencode.json`:

```jsonc
{
  "plugins": [
    "C:/Users/<usuario>/.config/opencode/plugins/opencode-todo"
  ]
}
```

Перезагрузите OpenCode или используйте `/reload`. Если боковая панель не обновится автоматически, запустите `/reload` ещё раз.

## Использование

В ходе работы агент поддерживает список автоматически. Вы также можете:

- Открыть панель командой `/todos`.
- Нажать `c`, чтобы очистить список с подтверждением.
- Нажать `Esc`, чтобы закрыть панель.

### Статусы

| Статус | Значок | Отображение |
| --- | --- | --- |
| `pending` | `•` | Нейтральный маркер, обычный текст |
| `in_progress` | `▸` | Маркер и текст цветом предупреждения из темы |
| `completed` | `✓` | Маркер цветом успеха, приглушённый текст |

Длинные тексты переносятся под заголовок, не возвращаясь в столбец со значком.

## Поведение

- Данные хранятся в `todos/<sessionID>` и сохраняются после перезапусков.
- Когда субагент записывает данные, список сохраняется в корневой сессии, чтобы отображаться в основной боковой панели.
- Пункты с одинаковым названием сохраняют `id` при обновлении.
- Когда все пункты завершены, следующий запрос очищает список, чтобы отображалась только текущая задача.
- TUI читает данные через RPC (`todo.list`) и отслеживает событие `todo.changed`.

## Инструменты для модели

### `todo_write`

Заменяет весь список. Всегда отправляйте все пункты, а не только изменения.

```json
{
  "todos": [
    { "title": "Реализовать конечную точку", "status": "completed" },
    { "title": "Проверить интеграцию", "status": "in_progress" },
    { "title": "Опубликовать релиз", "status": "pending" }
  ]
}
```

### `todo_list`

Читает текущий список задач сессии.

## Структура

| Файл | Ответственность |
| --- | --- |
| `src/rpc.ts` | Контракт RPC: `todo.list`, `todo.clear` и событие `todo.changed` |
| `src/index.ts` | Инструменты, хранилище, RPC и автоматическая очистка |
| `src/tui.tsx` | Блок в боковой панели и панель `/todos` |
